# Issues

[BACKLOG.md](./BACKLOG.md) is the queue: what is next, in order, and what is
parked and why. Every other file is one dated decision, `YYYYMMDD-topic.md`:
the question, what was weighed, the numbers it was decided on.

A record stays while the code or the documents cite it; one nothing cites is
removed, and git keeps it. What the system _is_ belongs in `README.md`,
`ARCHITECTURE.md` or a README beside the code, not here. A measurement goes
under [`experiment/`](./experiment/), dated, with its procedure and numbers.
