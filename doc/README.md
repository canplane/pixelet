# The record

What the system is lives in `README.md`, `ARCHITECTURE.md` and the READMEs
beside the code. This folder holds how it came to be that way, and what is
next. Each kind below is its own folder or file, and nothing here is
rewritten to match today: a record names the files and facts of its day.

- [backlog.md](./backlog.md) — what is queued, in priority order, one line
  each, pointing at where its reasoning lives.
- [decision/](./decision/) — one dated decision a file: the question, what
  was weighed, and what decided it. A decision binds while the code or the
  documents cite it; one nothing cites any more moves to `closed/`
  unchanged.
- [experiment/](./experiment/) — measurements, dated, each with its
  procedure and its numbers.
- [discussion/](./discussion/) — a dated discussion that decided nothing:
  why a path was taken, what was compared on the way, and where it points.
  It is read for reasons, never as a rule. Where one leads to a rule, the
  rule is written as a decision.

A report or a request from outside the project is a GitHub issue. What is
decided in one is written here, and the issue links to it.
