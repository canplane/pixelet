# Decisions

Every file here is one dated decision, `YYYYMMDD-topic.md`: the question,
what was weighed, the numbers it was decided on. What is queued next is
[BACKLOG.md](../BACKLOG.md).

A record stays here while the code or the documents cite it. One nothing
cites any more moves to [`closed/`](./closed/), unchanged: a decision settled
and passed, which names the files and facts of its day rather than today's,
and is read for why something went the way it did, never for what is.

What the system _is_ belongs in `README.md`, `ARCHITECTURE.md` or a README
beside the code, not here. A measurement goes under
[`experiment/`](./experiment/), dated, with its procedure and numbers.
