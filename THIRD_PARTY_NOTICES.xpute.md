# Third-party notices

Two files here are ports of someone else's code rather than our own — one
port, in two languages — and its license asks for a notice to travel with the
copy. Each carries that notice inside itself; this records where it came from.

This file covers copied source only. Crates and packages that are merely
depended on are not listed: `crates/Cargo.toml` and the package manifests name
them, and each carries its own license where it is published.

## evanw/buddy-malloc — `crates/xpute/core/src/alloc/buddy_tree.rs`, `cpp/xpute/core/alloc/buddy_tree.hpp`

Both files are [evanw/buddy-malloc][buddy] (MIT) line for line, the Rust and
the C++ each in its language, and the notice is at the top of each.

[buddy]: https://github.com/evanw/buddy-malloc
